Sample delivery terms

This demonstration page belongs to a local WordPress installation used to test the Dzen Chat integration. It is not a real shop, order or service offer. All terms below are fictional and exist only to test search over website content. The page helps verify that published content enters the index, text changes update answers, and drafts and protected posts stay outside public synchronization.

Price and timing

In this sample, standard delivery costs 350 rubles. Delivery takes three business days after confirmation. Collection is free. The fictional collection point opens Monday to Friday, from 10:00 to 18:00. The control code for these test terms is BEACON-47. It is used only to verify exact retrieval from this page.

If a visitor asks about the delivery price, the assistant should use this page and answer 350 rubles. If they ask about timing, the answer should specify three business days. For this example, business days are Monday to Friday, without adjusting for holidays. This information does not promise a real delivery because it is used only on a test site.

Changing an address

The address can be changed before the fictional order is handed to a courier. The visitor contacts support with the order number and new address. After handover, an operator must confirm any change. The assistant explains the process but does not collect personal data or place a real order in this demonstration.

Checking updates

After publication, WordPress notifies the service of this page's URL. The service retrieves and processes the public text itself. If the author changes the price or timing, WordPress submits the URL for reindexing again. Accepting a notification does not mean the new content is searchable yet: check processing in the Index section.

To verify the integration, open the public page, check the real widget, ask about these terms and find the same conversation in WordPress. Separately check source links, persistence of the selected widget and absence of secret keys in page code. This demonstration performs no real payments, purchases or shipments.
